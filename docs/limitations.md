# 制約とExcel忠実度

## PhpSpreadsheetによる再保存

Rust版Editorは対象XMLだけを書き換え、未変更のXLSX ZIP部品をそのまま複製します。PhpSpreadsheetはブック全体をオブジェクト化して再保存するため、同じバイト単位保存保証はありません。

グラフ読込・書込は有効化していますが、次の内容を含むブックは変更・欠落する可能性があります。

* マクロ、デジタル署名、ActiveX、OLE埋込
* ピボット、外部接続、未対応のOOXML拡張
* 高度なグラフ・画像・条件付き書式・データ検証の一部
* 共有数式、配列数式、データテーブル数式の特殊な保存状態

これらを保持する必要があるテンプレートは、実運用前に対象ファイルで往復テストしてください。マクロ有効ブック `.xlsm` は入力対象外です。

## 公開モデル

RawWorkbookは観測事実だけを持ち、見出し・必須項目・業務テーブルなどの意味解釈は行いません。日付形式の数値もExcelシリアル値のままです。

書込スタイルは番号形式、フォント、塗り、配置の一部だけです。罫線、条件付き書式、データ検証、画像、グラフは編集操作として公開しません。

## PHP 8.0

PHP 8.0は既にEOLです。本プロジェクトは互換性要件に合わせてPhpSpreadsheet 1.30系（最低1.30.6）へ限定し、`composer.lock` で検証済み版を固定します。ネットワークに面したサービスでは、ファイルサイズ制限、実行時間・メモリ制限、隔離されたワーカーを使用し、PHPの更新計画を持ってください。

## Retrievalとsemantic model

組込み検索は決定論的な小規模・テスト用途の字句索引です。プロセス終了後の永続化、言語解析、類義語検索、vector近傍検索は行いません。検索上限は1回20件です。

埋め込みのrequest/vector/index recordはprovider-neutralな配列契約だけを提供します。embedding provider SDK、HTTP呼出し、認証情報管理は意図的に実装していません。

semantic modelは外部で生成されたassertionを検証する層です。意味を推論・生成せず、引用されたRetrievalDocumentとsource rangeが同一source revisionで存在・被覆されることを検証します。検証成功はassertionの内容が正しいことを保証するものではありません。
